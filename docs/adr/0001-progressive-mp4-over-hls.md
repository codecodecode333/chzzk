# VOD 재생은 HLS가 아닌 Progressive MP4 + HTTP Range로 한다

방송 플랫폼이면 HLS 트랜스코딩(다중 화질, 적응형 스트리밍)이 자연스러운 선택이지만, 첫 단계에서는 업로드된 MP4 원본을 HTTP `Range` 요청으로 그대로 내려주고 `<video>`가 재생하게 한다. 트랜스코딩 파이프라인(ffmpeg, 작업 큐, "처리 중" 상태)이 범위를 크게 늘리기 때문이다. 그 대가로 업로드는 브라우저가 재생 가능한 MP4(H.264/AAC 가정)로 제한되고, 화질 선택·적응형 재생은 없다.

## Consequences

- 업로드 직후 바로 재생 가능하므로 VOD에 "처리 중" 같은 상태가 없다. HLS 도입 시 VOD 상태 모델이 새로 생긴다.
- 코덱은 검증하지 않으므로 H.265 등 브라우저가 못 여는 MP4가 등록될 수 있다.
